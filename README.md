Este repositório reúne os códigos desenvolvidos durante a formação **Java** da **Rocketseat**.

O objetivo deste projeto é consolidar os fundamentos da linguagem Java por meio de exemplos práticos e exercícios, servindo como base para o desenvolvimento de aplicações backend utilizando o ecossistema Spring.

## 🚀 Tecnologias

- Java
- Maven
- Git
- GitHub

##  Conteúdos estudados

Durante o desenvolvimento deste projeto foram praticados os seguintes conceitos:

- Sintaxe da linguagem Java
- Programação Orientada a Objetos (POO)
- Classes e Objetos
- Encapsulamento
- Herança
- Polimorfismo
- Abstração
- Interfaces
- Tratamento de Exceções
- Collections Framework
- Manipulação de Strings
- Estruturas de Repetição
- Estruturas Condicionais
- Métodos e Parâmetros
- Boas práticas de programação

##  Objetivo

Este repositório tem como finalidade registrar minha evolução no aprendizado da linguagem Java e servir como material de consulta para estudos futuros.

Os conhecimentos adquiridos aqui serão utilizados no desenvolvimento de aplicações mais robustas com tecnologias como:

- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Docker
- Spring Security
